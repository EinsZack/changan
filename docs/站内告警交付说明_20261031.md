# 站内告警交付说明

日期：2026年10月31日

本次在现有车群任务编排原型上增加站内任务告警，版本0.2.0。业务代码仍在服务器 /root/projects/changan-orchestrator 维护，并已将此前版本和本次开发纳入 https://github.com/EinsZack/changan 的main分支。

## 本次交付

- 任务超过截止时限或最终执行失败时，产生持久化站内告警。
- 网页提供顶部铃铛、未读数、提示条、告警列表、类型/阅读/处理状态筛选及任务跳转。
- 告警支持标为已读、确认、刷新后继续查询；同一任务不重复生成告警。
- 成功任务、主动取消、仍可重试的单次执行失败不触发任务级告警。
- 提供固定规则说明、API接口、后端测试和隔离浏览器验证工具。

## 验证结果

- 后端29项测试通过，其中9项为告警专项测试；保留1条第三方弃用警告。
- 浏览器2项端到端测试通过，覆盖超时、失败、主动取消、去重、已读确认、筛选、任务跳转及移动布局。
- 前端构建通过；桌面与手机截图已实际检查。
- 浏览器测试使用隔离数据库、禁用的测试节点和明确损坏的输入案例，不向运行环境执行器下发任务。
- 运行环境的正常视频、超时及重启保留验证见配套alerts-deployment-report.json，具体任务编号和结果以该文件为准。

## 使用与证据

使用步骤和接口见《站内告警使用说明》。服务器docs/目录保留alerts-unit-test-report.txt、alerts-browser-test-report.json和alerts-deployment-report.json。

数据库升级前备份保存在服务器data/backups/下，旧前端保存在tmp/pre-alerts-web-dist。运行数据库、GitHub凭据、模型、上传文件和依赖目录不提交到Git。

## 本版范围

仅站内提醒，不包含邮件、短信等站外渠道。告警规则固定，阅读和确认状态为当前共享原型的全局状态。确认告警不改变原任务结果，重跑是独立任务。未实现多用户通知收件箱、任意阈值配置或自动关联重跑恢复。历史已结束任务不批量补发告警。

当前验证环境为开发服务器及同机进程执行器，不代表真实车端部署或验收。原有0.1.0发布包保持历史版本，本次源码和接口以Git仓库0.2.0对应提交为准。
