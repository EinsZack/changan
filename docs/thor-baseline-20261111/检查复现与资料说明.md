## 常用只读复查

```bash
cat /etc/nv_tegra_release
uname -a
lscpu
free -h
df -h /
nvidia-smi
/usr/local/cuda/bin/nvcc --version
python3 -c 'import tensorrt, cv2; print(tensorrt.__version__, cv2.__version__)'
sudo docker info --format '{{.ServerVersion}} {{.Architecture}} {{.DefaultRuntime}}'
sudo docker ps -a --format '{{.Names}} {{.Image}} {{.Status}}'
sudo nvpmodel -q
ip -br -4 addr
ip route
systemctl is-active docker containerd k3s k3s-agent
```

完整 JSON `docker info` 可能包含代理等配置，不建议直接复制到交付资料。K3s当前未安装，相关 is-active 会返回 inactive，命令整体可能非0退出。

上述命令只复查环境。真正加入集群、运行容器和视频任务需按评估文档下一阶段执行；目前没有可宣称已完成的 Thor 项目部署命令。本轮没有在板卡创建项目源码、专用环境或常驻服务。
