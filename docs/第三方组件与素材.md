# 第三方组件与素材记录

本项目自研内容为任务业务建模、持久化事件链、调度与约束过滤、执行适配和幂等核对、视频任务聚合、触发策略、管理API和可视化。基础组件及预训练模型不作为自研算法成果。

| 内容 | 来源及版本 | 处理 |
|---|---|---|
| YOLOX Tiny ONNX | Megvii-BaseDetection/YOLOX，release 0.1.1rc0 | 上游项目Apache-2.0；下载URL和SHA256见assets/manifest.json及checksums.json；推理前后处理按上游公开方法实现 |
| 视频素材 | OpenCV仓库samples/data/vtest.avi前24秒 | 用于工程验证；文件SHA256已保存。对外展示/正式提交前核对素材权利，必要时替换甲方提供视频 |
| Redis | 官方redis.io，7.2.7 | 项目vendor目录编译；保留上游源码及COPYING，独立监听8390 |
| FastAPI、Pydantic、Uvicorn | PyPI固定版本 | 管理API、校验和HTTP服务 |
| OpenCV、ONNX Runtime、NumPy | PyPI固定版本 | 解码、检测推理和数值计算 |
| imageio-ffmpeg | PyPI 0.6.0携带FFmpeg二进制 | 视频切分与H.264转码；发布二进制时需随同上游许可证说明 |
| React、Vite、Lucide | npm，package-lock.json固定 | 网页界面与构建 |
| Playwright | npm，package-lock.json固定 | 浏览器验收和录屏，仅测试工具 |

精确版本以requirements.lock.txt、environment.linux-64.lock.txt及web/package-lock.json为准。外部资源首次下载由bootstrap.sh完成并核对assets/checksums.json，原始视频、模型、Redis构建产物不提交到Git源码仓库。

正式白盒交付前仍需项目负责人统一审查开源许可、模型及素材使用范围；本记录是工程来源清单，不代表已完成团队法律审核。
